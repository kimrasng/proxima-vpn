# New-online UUID admission contract and verification

One account subscription URL can issue several UUIDs, but concurrent admission is now keyed by account and UUID rather than TCP connection. A slot is atomically reserved across Exits before an authenticated local SOCKS CONNECT or UDP ASSOCIATE returns success to Xray. The existing UUID can open more streams using the same slot. A newcomer at the plan's max_concurrent cap receives a terminal `concurrency_limit` denial, never causes eviction of an incumbent, and never forwards payload. A cap of 0 retains the unlimited convention.

The Exit agent reports UUIDs with still-open admitted TCP/UDP associations, including idle ones, every 10 seconds. An account slot has no TTL. A fleet-complete reconciliation uses fenced agent generations/sequence, Redis server-side report timestamps and a reservation nonce; absence must survive a 30-second window before a slot is released. Missing/stale Exit reporting does not mean disconnection: new UUIDs remain blocked until complete evidence or operator recovery. A pre-admission report cannot release a new reservation.

**Targeted verification:** focused Go tests passed for TCP/UDP pre-success capacity rejection and incumbent continuity. Against disposable PostgreSQL17 and Redis7, `TestReserveAccountUUIDSlotAcrossExits`, `TestUUIDSlotReconciliationPreAdmissionAndIdle`, and `TestUUIDSlotReconciliationReleasesDisconnectedAfterTwoFreshEpochs` executed and passed with no skips. Test containers were removed; pre-existing unrelated Docker containers and volumes were left untouched.

**Not yet established:** full deployed two-Exit admission across real Xray agents plus control-plane restart; bounded admission latency/load under production scale; operator recovery for a permanently unknown Exit. Xray/Reality authentication may finish before the outbound SOCKS success/denial, so this guarantees no destination SOCKS success or payload forwarding for a denied UUID, not a rejection at the VLESS handshake. Do not claim production rollout without these checks.
